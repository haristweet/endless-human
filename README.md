# ENDLESS HUMAN

ポリゴンの顔が、カメラの角度を変えながら延々と歌うのを眺めるアプリ。そのまま MP4 に書き出せる。
1980年代のコンピューターグラフィックスの「顔が歌う」ミュージックビデオのような見た目をねらった。
[ENDLESS DUNGEON](https://haristweet.github.io/endless-dungeon/)・[FLIGHT](https://haristweet.github.io/endless-flight/)・[WALK](https://haristweet.github.io/endless-walk/)・[DRIVE](https://haristweet.github.io/endless-drive/)・[TRAIN](https://haristweet.github.io/endless-train/) の姉妹作で、書き出し・音・歌詞の仕組みは共通。
`index.html` と同梱の `mp4-muxer.js`・`opus-decoder.min.js` だけで動く（ビルド不要）。

## できること

- 顔4人（輪郭・あご・鼻・眉・頬骨・唇の形と、肌・髪・えりの色が違う）を順に入れ替える（10秒〜2分ごと。選んだ顔だけ）
- 写真から顔を作る：正面を向いた顔写真（生成した写真でも）を入れると、その顔が歌う（4枚まで）。写真から顔の478点を立体で読み取り、三角形ごとに写真の色を付ける。後頭部は顔の輪郭から丸くつなげて作る。写真はブラウザの中だけで使い、どこにも送らない。読み取った結果はブラウザに覚える
- 歌う口：入れた曲の、歌声のあたり（250〜2500Hz）の音の大きさで口が開く。歌詞があるときは、歌詞の出ている間だけ動かす。曲がないときは、それらしく動かす
- まばたき・目線の動き・うなずき（歌うと少しうなずく）
- カメラ：2秒 / 4秒 / 8秒ごとのカットで、正面〜斜め・ときどき横顔、口元や目元のアップに切りかわる。カットの中ではゆっくり動く。「カットなし」なら顔の周りをゆっくり回り続ける。動きの速さ3段階、番号（シード）で同じカメラワーク
- 描き方：線画（既定。隠れ線処理つき。線の色は顔ごと・白・緑・琥珀・水色・桃）/ ポリゴン
- 走査線（ブラウン管ふう：にじむ光・横線・四隅の暗がり）、画素の粗さ
- 画面の比率：4:3・16:9・1:1・4:5（縦長）
- MP4書き出し：音と歌詞（画面の下に字幕）、「曲のどこから」、長さ「15秒」〜「10分」、30 / 60コマ/秒
- 終わり方：曲を入れて「BAD END にする」にチェックを入れると、終わりの3.6秒前から顔がぶれて線が赤く染まり、終わりの2.6秒前にポリゴンの破片に砕け散る。暗転して「BAD END／歌は ここで 途切れた」

## しくみのメモ

- **顔**：球を横44×縦36に分け、顔立ちのパラメータ（`KINDS`）で形を変える（`headPt`）。あごへ向かって細くし、前側だけに鼻・眉・目のくぼみ・頬骨・あご先・唇のふくらみをガウスの山で足す。目は小さな球（まばたきでつぶれ、黒目は目線へ）、耳は輪、首とえりは円柱。毎コマ作り直す（`headMesh`）。
- **口**：唇の線（`MOUTH_Y`）より下の前側を、開きに合わせて下げる（あごが落ちる）。唇の線をまたぐ四角は口の中の色にする。
- **音から口へ**：曲を読んだときに、帯域を絞った音の大きさを 1/60 秒ごとに求め（`voiceEnv`）、上位5%で割ってならす。`mouthOpen` で開きにする。
- **カメラ**：カットの番号から決まる乱数で、角度・距離・ねらう高さを決める（`Sim.shot`）。
- **バッドエンド**：崩れる前は頂点をぶらし、線の色を赤へ寄せる。砕けたら三角形ごとに、外へ回りながら飛ばし、小さくする（`shatter`）。カメラは引く。音（デジタルのノイズ・下がっていく音・砕ける音）は `crashSfx()` で作り、書き出しでは曲の上に重ねる。
- **写真の顔**：同梱の MediaPipe（`vendor/mediapipe/`、Apache 2.0）の顔の点を取る仕組みを、写真を入れたときだけ読み込む（`landmarker`）。点の傾きを直し、あご先の高さ・鼻先の前後を頭に合わせる。三角形は、点のつながり（辺）から 3 点が互いにつながる組を拾う。口が開いた写真は、あごを上げて閉じた形に直してから使う。口は唇の合わせ目より下を下げて開け、口の中・白目・黒目は輪の中を扇形に塗る。まばたきは上まぶたの点を下まぶたへ寄せる。後頭部は、顔の輪郭（`OVAL`）の各点から、頭の中心のまわりを丸く回って後ろの一点へつなぐ（`photoFace`）。
- **描画**：ほかの ENDLESS と同じ WebGL2 の仕組み（重心座標で辺を線にする・線画は面を黒く塗って隠れ線処理）。
- ローカル確認：`python3 -m http.server 8804`
- 写真の顔の絵の確認：`node test/photo.cjs 顔写真.png 出力.png`（顔写真はリポジトリに入れない）
- 絵の確認：サーバーを立てて `node test/shots.mjs 出力.png`（顔ごとに線画とポリゴンを並べる）。BAD END を見るときは `TIMES=13,14.5,16.2,17.2,17.55,18,18.8,19.6 ROWS='[["a","wire",true,4,true]]'` のように時刻と［顔・描き方・走査線・カットの間隔・BAD END］を渡す
