# ENDLESS HUMAN

ポリゴンの顔が、カメラの角度を変えながら延々と歌うのを眺めるアプリ。そのまま MP4 に書き出せる。
1980年代のコンピューターグラフィックスの「顔が歌う」ミュージックビデオのような見た目をねらった。
[ENDLESS DUNGEON](https://haristweet.github.io/endless-dungeon/)・[FLIGHT](https://haristweet.github.io/endless-flight/)・[WALK](https://haristweet.github.io/endless-walk/)・[DRIVE](https://haristweet.github.io/endless-drive/)・[TRAIN](https://haristweet.github.io/endless-train/) の姉妹作で、書き出し・音・歌詞の仕組みは共通。
`index.html` と同梱の `mp4-muxer.js`・`opus-decoder.min.js` だけで動く（ビルド不要）。

## できること

- 顔4人（輪郭・あご・鼻・眉・頬骨・唇の形と、肌・髪・えりの色が違う）を順に入れ替える（10秒〜2分ごと。選んだ顔だけ）
- 写真から顔を作る：正面を向いた顔写真（生成した写真でも）を入れると、その顔が歌う（4枚まで）。写真から顔の478点を立体で読み取り、三角形ごとに写真の色を付ける。後頭部は顔の輪郭から丸くつなげて作り、写真の髪の外形（前から見た形）に合わせて広げて髪にする。真横の写真も一緒に選ぶと、横から見た頭の外形と、後ろの髪と肌の塗り分けも写真に合わせる（後ろ姿の写真は使わない）。写真はブラウザの中だけで使い、どこにも送らない。読み取った結果はブラウザに覚える
- 歌う口：入れた曲の、歌声のあたり（250〜2500Hz）の音の大きさで口が開く。歌詞があるときは、歌詞の出ている間だけ動かす。曲がないときは、それらしく動かす
- まばたき・目線の動き・うなずき（歌うと少しうなずく）
- カメラ：2秒 / 4秒 / 8秒ごとのカットで、正面〜斜め・ときどき横顔、口元や目元のアップに切りかわる。カットの中ではゆっくり動く。「カットなし」なら顔の周りをゆっくり回り続ける。動きの速さ3段階、番号（シード）で同じカメラワーク
- 描き方：線画（既定。隠れ線処理つき。線の色は顔ごと・白・緑・琥珀・水色・桃）/ ポリゴン / 時間で切り替え（ポリゴンと線画を交互に。切り替えの間隔はカットごと・8秒・15秒・30秒。カットなしならカットごとは 8 秒）
- 走査線（ブラウン管ふう：にじむ光・横線・四隅の暗がり）、画素の粗さ
- 画面の比率：4:3・16:9・1:1・4:5（縦長）
- MP4書き出し：音と歌詞（画面の下に字幕）、「曲のどこから」、長さ「15秒」〜「10分」、30 / 60コマ/秒
- 終わり方：曲を入れて「BAD END にする」にチェックを入れると、終わりの3.6秒前から顔がぶれて線が赤く染まり、終わりの2.6秒前にポリゴンの破片に砕け散る。暗転して「BAD END／歌は ここで 途切れた」

## しくみのメモ

- **顔**：球を横44×縦36に分け、顔立ちのパラメータ（`KINDS`）で形を変える（`headPt`）。あごへ向かって細くし、前側だけに鼻・眉・目のくぼみ・頬骨・あご先・唇のふくらみをガウスの山で足す。目は小さな球（まばたきでつぶれ、黒目は目線へ）、耳は輪、首とえりは円柱。毎コマ作り直す（`headMesh`）。
- **口**：唇の線（`MOUTH_Y`）より下の前側を、開きに合わせて下げる（あごが落ちる）。唇の線をまたぐ四角は口の中の色にする。
- **音から口へ**：曲を読んだときに、帯域を絞った音の大きさを 1/60 秒ごとに求め（`voiceEnv`）、上位5%で割ってならす。`mouthOpen` で開きにする。
- **カメラ**：カットの番号から決まる乱数で、角度・距離・ねらう高さを決める（`Sim.shot`）。
- **バッドエンド**：崩れる前は頂点をぶらし、線の色を赤へ寄せる。砕けたら三角形ごとに、外へ回りながら飛ばし、小さくする（`shatter`）。カメラは引く。音（デジタルのノイズ・下がっていく音・砕ける音）は `crashSfx()` で作り、書き出しでは曲の上に重ねる。
- **写真の顔**：同梱の MediaPipe（`vendor/mediapipe/`、Apache 2.0）の顔の点を取る仕組みを、写真を入れたときだけ読み込む（`landmarker`）。点の傾きを直し、あご先の高さ・鼻先の前後を頭に合わせる。三角形は、点のつながり（辺）から 3 点が互いにつながる組を拾う。口が開いた写真は、あごを上げて閉じた形に直してから使う。口は唇の合わせ目より下を下げて開け、口の中・白目・黒目は輪の中を扇形に塗る。まばたきは上まぶたの点を下まぶたへ寄せる。後頭部は、顔の輪郭（`OVAL`）の各点から、頭の中心のまわりを丸く回って後ろの一点へつなぐ（`photoFace`）。
- **髪の形**：同梱の髪の切り抜き（`hair_segmenter.tflite`）で写真の髪の所を取り、輪郭の各点から外へたどって髪の外側までの長さ（`hairR`）を測る。後頭部の各列を、前から見た外形がその長さになるように広げる（後ろの一点へは元に戻す）。前を向いた面には、写真の髪の色を細かいます目（`HG`）で覚えたものを混ぜる。髪の後ろ側の形は正面の写真に写っていないので、正面だけなら丸く作った形のまま。
- **頭全体を写真で塗る**：顔のまわりは輪郭のすぐ内側の色（`ovc`）、前を向いた所は正面の写真の色（`HG`）、耳より後ろの横を向いた所は横顔の写真の色（`SG`）を、面の向きに応じて混ぜる。顔と同じく光を当てずに写真の色のまま描き、向きで少しだけ明るさを変える（顔とのつなぎ目と、全身タイツのような一色の頭をなくす）。耳は正面の写真で頬のはしから外へ出た肌の所を測って作り（`photoEar`）、首は顔の幅に合わせて太くし、あごの下の色で塗る。えりの色も写真から取る。
- **口**：写真は口を閉じているので、下唇の内側のふちも上唇と同じ高さにある。開けるときは上唇の内側と口の端を残し、下唇（内側のふちも）とあごをほぼ一緒に下げる。点のつながりから拾った三角形のうち、上唇の内側と下唇の内側をまたいで口をふさぐものは除く（`mouthTris`）。口の中は唇の内側の輪から奥の一点への暗いおわん、上の歯の帯、奥の舌。
- **顔だけ**：「写真の顔の見せ方」が「顔だけ（暗闇に浮かぶ）」（はじめはこちら）のときは、後頭部・耳・首・えりを作らず、写真の顔の面だけを描く。顔のふちは、輪郭（`OVAL`）から三角形のつながりで何段内側か（`ringDepth`）で、輪郭ほどなめらかに暗くして暗闇へ溶かす。「頭まで」で今までどおり耳・髪・首まで作る。
- **光と目**：写真の頭は、写真の色に面の向きに応じた明るさ（`phShade`。正面 0.95・光の反対の横 0.5 くらい）を掛けて、横を向くと光が回って見えるようにする。目は目玉の球（`photoEye`）。大きさは目の幅の 0.55 倍で、まぶたのふちのどの点も球の表より少し前に出る深さに置く（突き抜けない）。黒目の所は角膜としてふくらませ（横から見ると前へ出る）、白目は光・目じりほど暗く・上まぶたの影で塗り分け、映り込みは光の向きに置く（目が動いても光の方に残る）。まぶたの穴の奥は影の色のおわんでふさぎ、まばたきの間は目玉を少し奥へ引く。顔のふちの三角形は背景に当たった角を除いて色を取る。走査線モードのにじんだ光は、ポリゴンでは弱くする（白く飛ばない）。
- **横顔**：顔の点が取れない写真は、背景（ふちの色）と違う所を人、髪の切り抜きを髪として外形を取り、髪の下の帯で肌が片側へ寄っていれば横顔（寄った側が顔の向き）、寄っていなければ後ろ姿とみなす（`silhouette`）。横顔は、いちばん前へ出た所を鼻先として、正面の顔の鼻先と頭のてっぺん（`ref`）に大きさと位置を合わせ、頭の中ほどから真上〜後ろの角度ごとに外形までの長さ（`rs`）と、横から見た髪・肌のます目（`SG`）を測る（`sideFit`）。後頭部の点はその長さに合うように角度ごとに広げ縮めし、髪と肌はます目で塗り分ける（横からは左右が分からないので、正面で髪の外形を測った列の前の方は正面のまま）。横顔は一緒に選んだ正面の顔（なければ最後に作った顔）に足す。
- **描画**：ほかの ENDLESS と同じ WebGL2 の仕組み（重心座標で辺を線にする・線画は面を黒く塗って隠れ線処理）。
- ローカル確認：`python3 -m http.server 8804`
- 写真の顔を画面と同じ見え方（ポリゴン・走査線あり、寄り）で確認：`node test/look.cjs 顔写真.png [横顔.png] 出力.png`（正面・斜め・横顔・目の寄り・口を開けた横顔・斜め後ろ。`STYLE=wire`・`CRT=0` も）。直したら必ずこれで見る
- 写真の顔の口の確認：`node test/mouth.cjs 出力.png 顔写真.png`（開き 0・0.5・1 を正面から、1 を斜め・横・下から。穴になって歯と舌が見えること）
- 写真の顔の目の確認：`node test/eyes.cjs 出力.png 顔写真.png [横顔.png]`（まばたき 3 段階と目線 3 方向。閉じたまぶたから黒目が出ないこと）
- 写真の顔の絵の確認：`node test/photo.cjs 顔写真.png [横顔.png] 出力.png`（顔写真はリポジトリに入れない。終わりの5コマは頭の全体を正面・斜め・横・後ろ寄り・上から）
- 絵の確認：サーバーを立てて `node test/shots.mjs 出力.png`（顔ごとに線画とポリゴンを並べる）。BAD END を見るときは `TIMES=13,14.5,16.2,17.2,17.55,18,18.8,19.6 ROWS='[["a","wire",true,4,true]]'` のように時刻と［顔・描き方・走査線・カットの間隔・BAD END］を渡す
